Change the tutoring password

For Byungmoon only. This page makes a new key.json. Nothing changes on the site until that file is pushed to GitHub, and the PDFs themselves are not re-encrypted.

Then:
  1. Move the downloaded key.json into C:\Users\byung\repos\byungmooncho.github.io\tutoring\, replacing the old one.
  2. In PowerShell:
    cd C:\Users\byung\repos\byungmooncho.github.io
    git add tutoring/key.json
    git commit -m "Tutoring: change password"
    git push origin main
  3. Within a few minutes, the old password stops working, including on devices that stayed signed in.

Use at least 12 characters. The encrypted files are in a public repo, so a short password can be guessed offline.
