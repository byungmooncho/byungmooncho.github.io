Two-Object Kinematics Problems

Web version of the lecture slides by Dr. H. Trevor Johnson-Steigelman, adapted for PHY 118.

The idea Two objects are moving independently, and we want to determine where they meet each other. The trick is to write a separate copy of the kinematics equations for each object, tagged with subscripts, and then use what the two objects share — the same position at the same instant — to link the copies together. A police car chasing a speeder is the classic example, and it ends with a quadratic equation that has two roots. Only one of them makes sense.

Two-object problems

Two objects are moving independently, and we want to determine where they meet each other. Typical examples: running to catch a train; a police car and a speeder.

Use multiple “versions” of the equations, using subscripts to keep track of them:

Speeder (subscript s)
xs = xos + vos t + ½ast²
Police (subscript p)
xp = xop + vop t + ½apt²

Often, one or more of the variables is “shared” by each object:

  • Initial and/or final position — they start together, or they end up at the same spot.
  • Meeting time — “catching up” means being at the same place at the same instant.
The key move A shared variable lets you set two equations equal to each other. If both objects are at xf at time tf, then xs(tf) = xp(tf) — one equation in one unknown.

Example problem — catching a speeder

A motorist (the Speeder) is driving at a constant rate of 35 m/s. He drives past a patrol car, but doesn't see it. The driver of the patrol car (the Police) takes 5 seconds to start moving, and then begins to follow.

Assuming that the patrol car accelerates smoothly at 3.0 m/s² for the entire chase, how long does it take for the Police to catch up to the Speeder?

Write down known data

Speeder
xos= 0 m
vos= 35 m/s
as= 0 m/s² (constant speed)
Police
xop= 0 m
vop= 0 m/s (starts from rest)
ap= 3 m/s²
Shared
t5= 5 s (police start moving)
xf, tf= same for both at the catch

Set up equations

Speeder
xf = xos + vosΔtf + ½asΔtf²
xf = 0 + vosΔtf + 0
xf = vos tf
Police
xf = xop + vop(tf − t5) + ½ap(tf − t5)²
xf = 0 + 0 + ½ap(tf − t5)²
xf = ½ap(tf − t5)²
Watch the time interval The speeder has been moving since t = 0, so its interval is just tf. The police car only starts at t5, so its interval is (tf − t5) = Δt. Forgetting this is the most common error in the whole problem.

Combine equations — catch up at xf

Try each step yourself before revealing it.

vos tf = xf = ½ap(tf − t5)²

Both cars are at the same place at the same time — that is what “catch up” means.

2vos tf = ap(tf − t5)²
2vos tf = ap(tf² − 2tft5 + t5²)
2vos tf = aptf² − 2aptft5 + apt5²
0 = aptf² − 2aptft5 − 2vostf + apt5²
0 = aptf² − 2(apt5 + vos)tf + apt5²
0 = At² + Bt + C

A quadratic in tf. Identify A, B, C — including their signs — before reaching for the formula.

0 = 3 m/s² tf² − 2{(3 m/s²)(5 s) + 35 m/s} tf + 3 m/s² (5 s)²
0 = 3 m/s² tf² + {−100 m/s} tf + 75 m

It is okay to enter numbers before using the quadratic formula — in fact it is much cleaner. Keep the units attached.

tf = −B ± √(B² − 4AC)2A = −{−100 m/s} ± √((−100 m/s)² − 4 · 3 m/s² · 75 m)2 (3 m/s²)
tf = 100 m/s ± √(10000 m²/s² − 900 m²/s²)6 m/s² = 100 m/s ± √(9100 m²/s²)6 m/s²

Check the units under the root: (m/s)² and (m/s²)(m) = m²/s² agree, so the subtraction is legal. And (m/s)/(m/s²) = s, as a time must be.

tf+ = 32.6 s   or   tf− = 0.77 s

The quadratic equation always produces two answers. Which one is the physics?

Choosing between the two solutions

The quadratic equation always produces two answers. You need to think about the situation and choose the most applicable of the two.

tf+ = 32.6 s — better answer

They meet down the road, after the police car has actually been moving for 27.6 s. This is the catch.

tf− = 0.77 s — not a good answer

This “meeting” happens before the patrol car moved. It would be possible only if the patrol car had followed the same parabola for the whole time of the problem — the dashed extension of the curve to the left of t5, which never happened.

Make sure you measure relative to the right starting point Both roots are perfectly good mathematics: they are where the line and the full parabola intersect. Only one is good physics, because the police equation is only valid for t ≥ t5.

Alternative methods

You do not have to keep t5 inside the equations. Another route:

  • Find the speeder's position at 5 s: (35 m/s)(5 s) = 175 m. That is the speeder's new “starting position” when the chase begins.
  • Have both moving for the remaining time Δt: 175 m + (35 m/s)Δt = ½(3 m/s²)Δt², which gives Δt = 27.6 s.
  • May need to add 5 s to the resulting time: 27.6 s + 5 s = 32.6 s — the same answer.
Same physics, different clock Resetting the clock to the moment the police start makes the algebra shorter, but you must remember to move the speeder ahead by 175 m and to add the 5 s back at the end if the question asks for time since the speeder passed.

If you stick with the variables, it can get ugly…

Carrying the symbols all the way through the quadratic formula looks like this:

Symbolic solution (for comparison)
tf = 2(apt5 + vos) ± √(4(apt5 + vos)² − 4ap²t5²)2ap
tf = (50 m/s) ± √(2500 (m/s)² − 225 (m/s)²)3 m/s² = 50 ± √22753 s
tf+ = 32.6 s   or   tf− = 0.77 s

Same answers, more places to slip. It is okay to enter numbers before using the quadratic equation.

Review — the procedure

  1. Write down known data, with a separate subscript for each object.
  2. Draw a sketch — a position–time graph with both objects; the meeting is where the curves cross.
  3. Set up equations — one copy of the kinematics equation per object, each with its own time interval.
  4. Combine equations through the shared variable (same xf at the same tf).
  5. Solve for the unknown — here a quadratic; put numbers in first.
  6. Check answers — reject roots that fall outside the time when an equation is valid, and sanity-check the sizes.
