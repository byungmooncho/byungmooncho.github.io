Angular Variables

Web version of the lecture slides by Dr. H. Trevor Johnson-Steigelman (Physics This Week), adapted for PHY 118.

The idea A spinning wheel is awkward to describe with x, v and a, because every point on it has a different speed and none of them goes anywhere. Measure the angle instead and the problem collapses: one number describes the whole rigid body, and the kinematics you already know comes across unchanged, symbol for symbol. This page sets up that translation and then links it back — because the tyre still has to grip the road, and that is a linear speed.
You already know this Everything from Module 1: v = Δx/Δt, a = Δv/Δt, and the three kinematics equations for constant acceleration. Nothing on this page is a new law. It is the same kinematics with new letters, plus the two equations that convert between them.

Angular position, and why radians

Pick a reference line through the axis — conventionally the horizontal — and the angular position θ of any mark on the object is the angle from that line to the mark. One number now describes the whole rigid body, because every point on it turns through the same angle.

The angle is measured in radians, not degrees, and the definition is geometric rather than arbitrary: one radian is the angle whose arc length equals the radius.

θ— angular position, in radians
s— arc length — the distance actually travelled along the rim
r— radius; D is the diameter, C the circumference
Trevor's question

What is the dimension of a radian?

A. degrees  ·  B. [L]  ·  C. [L]2  ·  D. [1]

D — a radian is dimensionless. Solve C = πD for π and you get C/D = [L]/[L]. The same thing happens to the angle: θ = s/r = [L]/[L]. A radian is a ratio of two lengths, so “rad” is a reminder of what you measured, not a unit that has to balance in a dimensional check.

Angular velocity

Exactly as linear speed is displacement over time, angular velocity ω is angular displacement over time.

Angular velocity
ω = ΔθΔt  =  θf − θiΔt

Units are rad/s. Because a radian is dimensionless, rad/s is really just s−1 — which is why the radian can appear and disappear in a unit conversion without anything going wrong.

Average, over an interval Every ω and α on this page is measured over an interval Δt, exactly as average velocity was in Module 1. For the constant-α problems in this module that is all you need, and the kinematics equations below assume it.

Why clockwise is clockwise

The two conventions point opposite ways, and Trevor's aside explains the collision. Mathematics measures angles counter-clockwise from the x-axis. Clocks run the other way because they inherited the shadow of a sundial: in the northern hemisphere the sun is due south and highest at noon, and as it travels east to west the shadow sweeps clockwise.

Other units, and the trap in them

Rotation rates arrive in whatever unit the device was sold in — rpm, rev/s, degrees per second. Trevor's worked case is a 45 rpm record, converted in one chain:

ω = 45 revmin × 1 min60 s × 2π rad1 rev = 3π2 rads = 4.71 rad/s

Revolutions cancel against revolutions and minutes against minutes, which is what makes the chain safe to write down in one line.

Be careful of mixing units You may use any angular unit you like, but every equation further down this page — s = rθ, vt = ωr, at = αr — is true only in radians. They are the equations that convert an angle into a length, and the radian is the only angular unit defined as a length ratio. Convert first, then substitute.

Period and frequency

The most direct way to measure uniform circular motion is to time one complete rotation. That time is the period T, and its reciprocal is the frequency f.

Angular acceleration

Angular acceleration is the rate of change of angular velocity — and its presence is exactly what makes the circular motion non-uniform.

Angular acceleration, and the equation it generates
α = ΔωΔt  =  ωf − ωiΔt   →   ωf = ωi + αΔt

Rearranging the definition gives the first kinematics equation, in rad/s2 — and it is the same rearrangement that turned a = Δv/Δt into v = v0 + aΔt in Module 1.

Once that first one is in hand the other two follow the same way, and the whole set can simply be read off the linear set by substitution:

Linear kinematicsRotational kinematics
v = v0 + aΔt ω = ω0 + αΔt
x = x0 + v0Δt + ½a(Δt)2 θ = θ0 + ω0Δt + ½α(Δt)2
v2 = v02 + 2a(x − x0) ω2 = ω02 + 2α(θ − θ0)
x → θ  ·  v → ω  ·  a → α
Trevor's warning, and it is the important sentence on the slide The variables behave similarly, but they are not the same. The substitution is a mapping between two descriptions, not an identity: θ is an angle and x is a length, and a problem that mixes them without the conversion equations below will give you a number with no meaning.

Linking linear and angular variables

The angular description is complete on its own, but it cannot tell you how fast the rim is moving — and the rim is where the belt rides, the tyre grips and the stopper on the end of the string gets released. Two equations do the conversion, and both come from s = rθ.

Differences work the same way, which is where the second conversion comes from: if vt = ωr then Δvt = (Δω)r, and dividing by Δt gives the tangential acceleration.

The two conversions, and the acceleration that is not one of them
at = ΔvtΔt = (Δω)rΔt = ΔωΔt r   →   at = αr
ac = vt2r = (ωr)2r   →   ac = ω2r

Two accelerations, two different jobs. The tangential one changes how fast the point is going; the centripetal one changes the direction it is going. They are perpendicular, so they never substitute for one another — and if ω is constant then Δω = 0 and there is no tangential acceleration at all, while ac is still there, still turning the velocity.

Review — useful equations

Arc length— s = rθ, with θ in radians
Angular speed— ω = Δθ/Δt, in rad/s
Angular acceleration— α = Δω/Δt, in rad/s2
Period— T = 2π/ω; f = 1/T
Tangential velocity— vt = ωr
Tangential acceleration— at = αr
Centripetal acceleration— ac = vt2/r = ω2r
Rotational kinematics— the three constant-α equations in the table above
