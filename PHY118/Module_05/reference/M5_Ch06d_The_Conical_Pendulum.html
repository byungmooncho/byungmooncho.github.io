The Conical Pendulum

Web version of the lecture slides by Dr. H. Trevor Johnson-Steigelman (Physics This Week), adapted for PHY 118.

The idea Hang a ball on a string and swing it so it sweeps out a horizontal circle instead of a back-and-forth arc. The string now traces a cone, and the problem becomes the cleanest worked example in the module: two directions, two different statements. Vertically nothing is accelerating, so the forces balance. Horizontally everything is accelerating, so the forces do not. One tension does both jobs, and resolving it into components is the entire solution.
You already know this Resolving a vector into components from Module 2, free-body diagrams from Module 3, and from Ch06a the banked-aeroplane pattern — vertical equilibrium alongside horizontal Newton's second law. The conical pendulum is that same pattern with a string instead of a wing.

What a conical pendulum is

An object on a string that moves in a horizontal circular path rather than back and forth like an ordinary pendulum. The string sweeps the surface of a cone — hence the name — and stays at a fixed angle θ from the vertical while it does.

Resolve the tension, then apply Newton's second law twice

Only two forces act on the bob: the tension along the string and its weight. The tension is the awkward one, because it points neither straight up nor towards the centre — so split it.

Two directions, two different statements
y direction — nothing is accelerating x direction — everything is
may = Fty − Fg, with ay = 0 mac = Ftx
mg = Ft cos θ mac = Ft sin θ
Ft = mgcos θ mac = mgcos θ sin θ  ⇒  ac = g tan θ

The left column is solved first and then substituted into the right — that is the whole trick. The mass cancels out of the horizontal result, so the angle a conical pendulum settles at depends on its speed and nothing else.

How fast must it move for a given radius?

Trevor's framing is worth keeping: ac = g tan θ is one way to express the centripetal acceleration, and ac = v2/r is the definition of it. Setting the two equal is what turns a force balance into a speed.

v2r = g tan θ   ⇒   v2 = g r sin θcos θ

Which is an answer in terms of the angle. To get it in terms of the lengths you can actually measure — the string and the radius — you need the geometry below.

The speed, in measurable quantities
v2 = g r tan θ = g r r√L2 − r2

Tie a known length of string, pick the radius you want the bob to sweep, and this is the speed it must have. Note what happens as the circle widens towards the full string length: the denominator collapses and the required speed runs away.

What is the tension at a given radius?

The same geometry answers the other question. Start from the vertical equation and substitute cos θ.

The tension, in measurable quantities
Ft = mgcos θ = mg√L2 − r2L   =   mgL√L2 − r2

This page's result differs from the slide's. Slide 5 substitutes r/√L2−r2 for cos θ and prints Ft = mg√L2−r2/r. That substitution is tan θ, not cos θ — and the slide's own limits, below, are what give the game away. The form above is the one consistent with both.

LimitWhat the geometry saysTension
r → 0 θ → 0° — the string hangs straight down and the bob barely moves Ft → mgL/L = mg, just the weight
r → L θ → 90° — the string is swung out towards horizontal Ft → mgL/0 → ∞
Why those two limits are worth the trouble They are a free check on the algebra, and here they catch a real error. At rest the string must carry exactly the weight; swung out flat it would need infinite tension, which is why a conical pendulum can never reach horizontal however hard you spin it. Any expression that fails either test is wrong, whatever it was derived from — run them every time.

Review

Conical pendulum— an object on a string sweeping a horizontal circle, the string tracing a cone at a fixed angle θ from the vertical.
The method— resolve the tension; vertical is equilibrium, horizontal is mac. Solve the vertical first, substitute into the horizontal.
Tension— Ft = mg/cos θ = mgL/√L2−r2
Acceleration— ac = g tan θ — independent of mass
Speed— v2 = g r tan θ = g r2/√L2−r2
