Handling Large and Small Numbers

Synopsis Physics is a quantitative science, and the numbers involved range from the enormous (the mass of the Earth: 5,980,000,000,000,000,000,000,000 kg) to the tiny (the diameter of an atom: 0.0000000001 m). Writing all those zeros is unworkable, so we use powers-of-10 notation and scientific notation instead — keeping only the meaningful (significant) digits and expressing the rest as a power of ten. This note also covers how to enter these numbers correctly on your calculator using the EE button.
Performance Expectations By the end of this note, you will be able to…
  • PE1 Write a number in powers-of-10 notation, keeping only the meaningful digits and expressing the rest as a power of ten.
  • PE2 Convert powers-of-10 notation into standard scientific notation (a single nonzero digit before the decimal point).
  • PE3 Apply the zero rules to count significant figures correctly: leading zeros never count, trailing zeros count only with an explicit decimal point, and zeros sandwiched between nonzero digits always count.
  • PE4 Enter numbers in scientific notation on a calculator using the EE button (not the ^ or 10ˣ buttons), including for multiplication, division, and powers.
5,980,000,...,000 → 5.98 × 10²⁴ same number, meaningful digits only
💡You already know this

You already treat trailing zeros differently depending on context, even if you've never named the rule:

💰 $340 vs. $340.00 A price tag "$340.00" feels more exact than "about $340" — the decimal signals precision.
📏 A tape measure with fine markings You round to the smallest line you can read — you don't invent extra precision you don't have.
🔋 "47%" vs. "47.0%" battery "47.0%" implies a more precise reading than a rounded "47%" — same idea as sig figs.

Zero rules at a glance

Four rules cover every case you'll see in this note:

Zero typeExampleSignificant?
Leading zeros0.00234 mNever
Trailing, no decimal point142000 sNever
Trailing, with decimal point100.00 kgAlways
Sandwiched between nonzero digits1004 mAlways

Looking ahead: here you're learning to write and count digits in scientific notation. In Note 2a, you'll use these same sig-fig rules inside actual calculations (multiplication, division, addition, subtraction) and learn how measurement precision translates into %error. The EE-button skill you practice here becomes essential once those calculations involve real physics formulas.

Key relationships for this note

  • 🔟 meaningful digits × 10n powers-of-10 notation — keep only significant digits, push the rest into the exponent
  • 🔬 d.ddd × 10n scientific notation — exactly one nonzero digit before the decimal point
  • 🧮 d.dddEn calculator EE-button entry — same value, no parentheses required
