2D Projectile Motion: Launch At Arbitrary Angles

Synopsis A ball launched at an angle is really two separate motions running on one clock: a horizontal motion at constant velocity, and a vertical motion in freefall. They don't interact — gravity never touches the horizontal component, and the horizontal component has no say in how fast the ball falls. So the first move is always the same: resolve the launch velocity. Splitting V0 into V0x = V0cosθ and V0y = V0sinθ lets us use the freefall equations from Note 4 on the vertical piece and the constant-velocity equation on the horizontal piece.

Everything in this note is a level-ground launch: the ball lands at the same height it was launched from. That makes the flight symmetric. It rises for exactly half the flight, falls for the other half, and lands with the same speed it left with. We find the flight time first, because it depends only on V0y, and then the maximum height H and the range D follow from it. The numbers we carry the whole way through are the launcher from class: 5 m/s at 30°.
Performance Expectations By the end of this note, you will be able to…

  • PE2Write the x and y equations for an angled launch: dx=V0xt, and dy=V0yt−½gt² with Vy=V0y−gt.
  • PE3Find the flight time of a level-ground launch, tflight=2V0y/g, and explain why it depends only on V0y.
  • PE4Find the maximum height H from the time to the apex, where Vy=0 and tapex=tflight/2.
  • PE5Find the range D=V0xtflight, and describe how the ball lands — same speed, angled θ below horizontal.
💡You already know this

Nothing here is brand new — you're combining three things you've already built:

📐 Resolving a vector (N2 / N3) Adjacent side → cosine, opposite side → sine. V0 splits the same way any vector does.
🍎 Freefall (N4) The vertical piece obeys the same v=v₀+at and d=d₀+v₀t+½at², with a=−g=−9.8 m/s² always.
🚗 Constant velocity (M1) Nothing pushes sideways, so the horizontal piece never changes: dx=V0xt for the whole flight.

Resolve the launch velocity

A ball leaves level ground with speed V0 at angle θ above horizontal. The horizontal side of the triangle is adjacent to θ, so it takes the cosine; the vertical side is opposite θ, so it takes the sine:

V0x = V0cosθ      V0y = V0sinθ
Figure 1. A launch from level ground. The launch velocity V0 splits into V0x (adjacent, cosine) and V0y (opposite, sine). The path is a parabola: it peaks at height H halfway through the flight, where Vy=0 but Vx is still V0x, and it lands a distance D away moving at the launch speed, angled θ below horizontal.

The launcher from class: V0=5 m/s at θ=30°.

V0x = 5cos30° = 4.33 m/s      V0y = 5sin30° = 2.5 m/s

Now that V0 is resolved into a horizontal and a vertical piece, and the two pieces are independent of each other, we can analyse the x motion and the y motion separately.

Two motions, one clock

Measure everything from the launch point, so d0=0 in both directions. The acceleration is zero sideways and ay=−g=−9.8 m/s² vertically — always, on the way up, at the top, and on the way down.

Horizontal (x)Vertical (y)
Positiondx = V0xt = (V0cosθ)tdy = V0yt − ½gt² = (V0sinθ)t − 4.9t²
VelocityVx = V0x = V0cosθ (never changes)Vy = V0y − gt = V0sinθ − 9.8t
5 m/s at 30°dx = 4.33t    Vx = 4.33 m/sdy = 2.5t − 4.9t²    Vy = 2.5 − 9.8t

The same t appears in both columns — that is the clock the two motions share. And because dy has a t² term while dx is just proportional to t, the path is a parabola.

First, find the flight time

On level ground the trip down mirrors the trip up, so the ball comes back to the ground moving downward at the speed it left with: Vy=−V0y at landing. Put that into the vertical velocity equation:

−V0y = V0y − gtflight   ⇒   2V0y = gtflight tflight = 2V0y/g = 2V0sinθ/g   (level ground)

The launcher from class:

−2.5 = 2.5 − 9.8tflight   ⇒   tflight = 5/9.8 tflight ≈ 0.51 s
Notice: V0x never appears. The flight time is set by the vertical motion alone, so a steeper launch at the same speed (bigger V0y) stays up longer. The horizontal speed only decides how far sideways the ball gets in that time. Same answer from the position equation: the ball is back on the ground when dy=0, so 0 = 2.5t − 4.9t², which gives t=0 (the launch) or t=2.5/4.9≈0.51 s (the landing).

Time to the apex

At the top of the arc the ball is moving purely sideways for an instant, so Vy=0 there:

0 = V0y − gtapex   ⇒   tapex = V0y/g = 2.5/9.8 tapex ≈ 0.255 s   = half of tflight

That is the symmetry of a level-ground flight: half the time going up, half coming down.

Maximum height, H

H is the vertical position at tapex. Put tapex into the vertical position equation:

H = V0ytapex − ½gtapex² = (5sin30°)(0.255) − (9.8/2)(0.255)² H = 0.6375 − 0.3186 H ≈ 0.32 m
Shortcut, same answer: putting tapex=V0y/g into that equation and simplifying gives H=V0y²/(2g). Check: 2.5²/(2·9.8)=6.25/19.6≈0.32 m. Use whichever you trust; both come from the same physics.

Range, D

The horizontal motion never changes, so the ball travels sideways at V0x for the whole flight time:

D = V0xtflight = (5cos30°)(0.51) D ≈ 2.21 m

In class we measured the launcher's landing spot at about 2.25 m — within a few centimetres of the prediction.

How it lands

At tflight, Vx is still 4.33 m/s and Vy=2.5−9.8(0.51)≈−2.5 m/s. Those are the launch components with the vertical one flipped, so the ball lands at 5 m/s, 30° below horizontal — the mirror image of the launch (Figure 1, right side).

Key equations — level-ground launch

Horizontal componentVertical component
Velocity (m/s)Vx = V0cosθV0y = V0sinθ
Flight time, tflight (s)—tflight = 2V0y/g = 2V0sinθ/g
Max. displacement (m)D = dx,max = V0xtflight = (V0cosθ)tflightH = dy,max = V0y(tflight/2) − ½g(tflight/2)²
Try it in the launcher: at the same speed, 30° and 60° land in the same spot. The 60° ball goes higher and stays up longer, but it moves sideways more slowly, and the two effects cancel exactly. Any pair of angles that add to 90° shares a range on level ground; 45° gives the longest range of all.
Your turn — a kicked soccer ball

A soccer ball is kicked from level ground at V0=12 m/s, 40° above horizontal. Use g=9.8 m/s². Work each part in your notes, then open the working to check.

  1. Resolve V0 into V0x and V0y.
  2. Find the flight time and the time to the apex.
  3. Find the maximum height H.
  4. Find the range D.
1) V0x = 12cos40° = 9.19 m/s    V0y = 12sin40° = 7.71 m/s
2) tflight = 2(7.71)/9.8 = 1.57 s    tapex = 7.71/9.8 = 0.787 s (half the flight)
3) H = (7.71)(0.787) − 4.9(0.787)² = 6.07 − 3.04 = 3.03 m  (shortcut: 7.71²/19.6 = 3.03 m)
4) D = V0xtflight = (9.19)(1.57) = 14.5 m
Where this fits: every result in this note assumes the ball lands at the same height it left from. In Note 4 the launch was horizontal from above the ground, so the drop height, not V0y, set the time. Here the launch and the landing are level, so the time comes from V0y alone — find it first, and everything else follows.
