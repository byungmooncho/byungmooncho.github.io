Formatting Data Tables for Lab Reports

Notes on the video by Dr. H. Trevor Johnson-Steigelman, Physics This Week, adapted for FLCC Physics.

The idea Raw data typed into Excel looks like a work in progress — ragged decimals, missing units, no structure. With a few minutes of formatting you can turn it into a table you'd be proud to put in a lab report: labeled with units, showing the precision you actually measured, decimals lined up, cleanly bordered, and pasted into Word so it stays intact.

Start with the labels — and always include units

Every column header must state the quantity and the unit it was measured in: time in seconds, distance in meters. A number without a unit is meaningless in a lab report.

Once the units are in, make the headers easy to read. In the video the labels get bold, a font size a step or two smaller so they fit (don't go too small), and a font choice such as Cambria. If a label still spills past the edge of its cell, adjust the column width — a little wider for the label, a little narrower where there's wasted space — until everything fits comfortably.

Show the precision you actually measured

Excel has a quirk: type 1.00 and hit Enter, and it displays 1 — the trailing decimal places vanish. But those zeros carry information: they say you measured to the hundredth of a second.

To fix it, select the whole column, then go to the Number area of the Home ribbon (the box that says General) and use the Increase Decimal / Decrease Decimal buttons until every value in the column shows exactly the precision of your measurement — no more, no less. If you measured more precisely, take it up a couple more places; if less, bring it down.

Calculated columns need this too Values produced by a formula (an analysis column — say, a distance divided by three) come out like a calculator display: as many digits as will fit, varying from row to row. Use Decrease Decimal on those columns as well, so calculated values match the precision of the data they came from.

Line up the decimal points

Excel normally pushes numbers against the right edge of the cell — that's good, because it lines the decimal points up. If you center the column, the decimals stop aligning and the table gets harder to read.

To keep the alignment but add breathing room, select the numbers and open Format Cells → Alignment, set Horizontal to Right (Indent), and set the indent to 1 (or 2 for a wide column — adjust until it looks right). The decimals stay lined up and the numbers sit comfortably inside their cells.

Precision beats sig-fig purism here In the goal table, 0.20 m has two significant digits and 1.00 m has three. Don't worry about that: in the table, what matters is displaying the precision you measured to, so the numbers align. When decimals don't line up, your eye jumps back and forth and the trend in the data is hard to see; when they do, you can follow the pattern straight down the column.

Add borders

Select the whole table and open the Borders drop-down (under Font on the Home ribbon). The recipe in the video: start with All Borders, then add a Thick Outside Border around the table, and one more thick border under the header row. That's not the only valid style — follow your professor's instructions, or a journal's requirements, if they specify one.

Put the table into your lab report

Select the finished table and copy it (Ctrl+C or right-click → Copy), then go to your lab report in Word — the experimental data section of the lab report template — and paste. Word offers several paste options, and the choice matters:

Recommended — paste as a Picture

The table becomes an image in Word. If you later change the Excel file, nothing breaks in the report; and any on-screen fuzziness is just the zoom level — it prints cleanly.

Positioning comes next: select the pasted picture, click Layout Options, and choose Square so your paragraphs wrap beside the table and you can discuss the data right next to it.

Avoid — Link & Use Destination Styles

A linked paste updates the report whenever the Excel file changes — which sounds handy, but if the Excel file is ever deleted or moved, the table in your report can become corrupted.

Keep Source Formatting works, but it doesn't always translate nicely. Paste as Picture is the reliable choice at this level.

Review

  • Column headers state the quantity and its unit; make them bold and size the columns so they fit.
  • Display every column to the precision you measured — use Increase/Decrease Decimal, including on calculated columns.
  • Keep numbers right-aligned with an indent so decimal points line up and trends are easy to see.
  • Borders: All Borders, a thick outside border, and a thick line under the header row (unless instructions say otherwise).
  • In Word, paste as a Picture and set Layout Options to Square; avoid linked pastes.
