Dimensions in Physics

A lesson by Dr. H. Trevor Johnson-Steigelman, adapted for PHY 105.

Why this matters Understanding dimensions and their typical units can give you super-powers in physics. By carefully looking at a measurement's dimension (like length) and its unit (like meters), you can often predict where it sits in an equation — and catch mistakes, like accidentally using m/s² as the units for speed. (The unit should be m/s.)

By the end of this lesson, you will be able…

  1. To define the two ways that physicists use the term dimension.
  2. To identify a system as spatially 1D, 2D, or 3D.
  3. To write down the base dimensions.
  4. To recall, identify, and use the base units in the SI system.
  5. To recall, identify and use compound units in the SI system, including area, volume, and density.

Meaning #1 — Dimensions as spatial relationships

The first way physicists use the word dimension is spatial: how many independent directions does a system live in?

0D — zero dimensional: exists only as a point.
1D — one dimensional: exists only along a line.
2D — two dimensional: exists only in a plane — a flat surface.
3D — three dimensional: exists in “normal” space.

Meaning #2 — Dimension as a type of measurement

We use square brackets to denote dimension. For example, [L] represents the dimension of “length”. Every dimension has a base unit in the SI (International System of Units — the metric system):

Combining measurements

Measurements can only be added or subtracted if they have the same dimension. You do it all the time:

5′10″  or  5 ft 10 in   [L] + [L]

5/19/2018 2:00 p.m. − 1/29/2018 9:00 a.m. = 111 days, 5 hours, 0 minutes   [T] − [T]

Putting it to work — checking an equation

Here is a kinematics equation from the next chapter. Checking dimensions and/or units helps catch mistakes: replace every quantity with its dimension (or unit), cancel, and see whether both sides match.

Checking dimensions
Δx = v₀·Δt + ½·a·(Δt)²
[L] = [L][T]·[T]  +  [1]·[L][T]²·[T]²
[L] = [L] + [L] ✓
Checking units
Δx = v₀·Δt + ½·a·(Δt)²
m = ms·s  +  [1]·ms²·s²
m = m + m ✓
Note The ½ is a pure number — it has no dimension (we write its “dimension” as [1]), so it never affects a dimension or unit check.

Review

  • Spatial dimensions and measurement dimensions differ slightly.
  • Learn the dimensions and units of the equations you are studying.
  • Check your units to help catch any potential mistakes.
