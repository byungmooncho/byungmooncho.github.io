Standing Waves On A String

SynopsisWe revisit standing waves on a string. When you pluck a guitar string, you set up a standing wave. What does it mean to set up a standing wave?

Jot down your thoughts before you read on.

Traveling waves in a string with both ends fixed. Forward- and backward-going waves interfere — same frequency, same wavelength. A standing wave forms: the nodes are fixed in space.

The condition for setting up a standing wave on a string with two fixed ends is that nodes are at the ends. This is obvious because the ends are fixed and have zero amplitude! With this simple (boundary) condition, you can understand the relationship between the wavelength and the frequency of the standing waves. Below is one such standing wave:

The 4th harmonic — four loops fit on the string, and the number of antinodes is the harmonic number.

Worked example

Take the string above: length L = 2 m, with a wave speed on the string of v = 330 m/s. Work out the wavelength and the frequency of each harmonic.

Each loop is half a wavelength, so n loops fit on the string when λn = 2L/n, and then fn = v/λn = n f1.

Harmonic #Frequency fWavelength λn = 2L/n
n = 1 — fundamentalf1 = 82.5 Hzλ1 = 4 m = 2L/1
n = 2 — 2nd harmonicf2 = 330 / 2 = 165 Hz = 2f1λ2 = 2 m = 2L/2
n = 3 — 3rd harmonicf3 = 330 / 1.33 = 248 Hz = 3f1λ3 = 1.33 m = 2L/3
n = 4 — 4th harmonicf4 = 4f1λ4 = 1 m = 2L/4
n = 5 — 5th harmonicf5 = 5f1λ5 = 0.8 m = 2L/5
n = 6 — 6th harmonicf6 = 6f1λ6 = 0.66 m = 2L/6

So on a string fixed at both ends every harmonic is allowed: n = 1, 2, 3, 4, 5, 6… Keep that in mind — the next note shows a pipe where that is not true.
