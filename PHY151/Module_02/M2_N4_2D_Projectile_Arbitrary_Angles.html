2D Projectile Motion: Launch At Arbitrary Angles

Synopsis A projectile launched at an angle is really two separate motions running on one clock: a horizontal motion at constant velocity, and a vertical motion in freefall. They don't interact — gravity never touches the horizontal component, and nothing about the horizontal component changes how fast the projectile falls. Splitting V0 into V0x = V0cosθ and V0y = V0sinθ lets us reuse the freefall equations from Note 3 on the vertical component, and constant-velocity equations on the horizontal one. Because only the vertical component ever stops and reverses, the flight time depends only on V0y — the horizontal speed is along for the ride. This note works a full numeric example (a launch off a cliff), then sets up the general question N5 finishes: given where you want to land, what angle do you launch at?

Setting up the components

A projectile is launched with speed V0 at angle θ above horizontal. As always, we resolve it into a horizontal and a vertical piece:

V0x = V0cosθ      V0y = V0sinθ

From this point on, treat the two components as two separate 1D problems sharing the same clock. Horizontally, nothing accelerates the projectile — Vx stays equal to V0x for the entire flight. Vertically, gravity acts the whole time, exactly like the freefall you already know:

Vy = V0y − gt

Why flight time depends only on V0y

At the very top of the arc — the apex — the projectile is momentarily moving purely horizontally, so vy=0 there. For a launch and landing at the same height, the trip down mirrors the trip up: the projectile returns to launch height moving at −V0y, the same speed it left with, just flipped. Setting Vy=−V0y in the equation above:

−V0y = V0y − gtflight   ⇒   2V0y = gtflight tflight = 2V0y / g   (level launch and landing)
Notice: V0x never appears. Two projectiles launched at the same angle but different speeds spend different amounts of time in the air; two projectiles launched at the same V0y but different V0x — meaning different angles and speeds — spend exactly the same time in the air. Horizontal motion just carries the projectile sideways for however long the vertical motion allows.

How high does it go?

Use the no-time kinematic equation on the vertical component, with a=−g and vy=0 at the apex:

vy² = v0y² − 2g·dy,max   ⇒   0 = (V0sinθ)² − 2g·dy,max dy,max = (V0sinθ)² / (2g)
Worked example — launch off a cliff

A ball is launched at V0=10 m/s, 25° above horizontal, from the edge of a 1.5 m cliff. Find the max height, flight time, range, and impact velocity. Use g=9.8 m/s².

  1. Components. V0x = 10cos25° = 9.06 m/s     V0y = 10sin25° = 4.23 m/s
  2. Max height above the launch point — apex is still reached before the ball ever gets near the base of the cliff, so the level-ground formula applies unchanged: dy,max = (10sin25°)² / (2·9.8) = 17.86/19.6 dy,max ≈ 0.91 m above the launch point
  3. Flight time — here the cliff matters. Launch and landing are not at the same height, so tflight=2V0y/g doesn't apply directly. Instead, write the full position equation, measuring from the launch point (landing is 1.5 m below it, so dy=−1.5 m there): dy = d0y + V0yt − ½gt²   ⇒   −1.5 = (10sin25°)t − 4.9t² 4.9t² − 4.23t − 1.5 = 0   (quadratic formula, keep the positive root) tflight ≈ 1.13 s
  4. Range — horizontal motion is constant-velocity the whole flight: dx,max = V0x·tflight = (9.06)(1.13) dx,max ≈ 10.2 m
  5. Impact velocity — recompute both components at t=tflight: Vx = V0x = 9.06 m/s  (unchanged)     Vy = V0y − gt = 4.23 − 9.8(1.13) ≈ −6.85 m/s speed = √(Vx²+Vy²) = √(9.06²+6.85²) impact speed ≈ 11.4 m/s, about 52.9° from vertical (≈37° below horizontal)
The impact velocity's angle can be measured from either axis — Dr. Cho's original work reports it from the vertical (52.9°), which is the same physical direction as about 37° below horizontal. Either description is correct as long as you say which axis you're measuring from; the Instructor Key has a note on this.

Turning the problem around: solving for θ

The worked example gave us V0, θ, and the cliff height H, and asked how far the ball goes. What if instead we're given V0, H, and a target distance D — and need to find the angle θ that lands exactly on it? Start from the same vertical position equation, but now solve for time using the horizontal equation first:

dx = (V0cosθ)t = D   ⇒   t = D / (V0cosθ) 0 = H + (V0sinθ)t − ½gt²   ⇒   0 = H + D·tanθ − gD²/(2V0²cos²θ)

Using 1/cos²θ = 1+tan²θ turns every θ in the equation into tanθ, which means this is really a quadratic equation in tanθ. Let x=tanθ:

0 = [H − gD²/(2V0²)] + D·x − [gD²/(2V0²)]·x²

Solve this with the quadratic formula for x, then θ=tan−1(x). A quadratic has (up to) two roots, so this equation typically hands back two launch angles that both reach the same target — one a high, arcing lob and one a lower, flatter shot.

Check it yourself: for H=1.2 m, D=1.5 m, V0=5 m/s, the bracketed quantities work out to gD²/(2V0²)=0.441 and H−0.441=0.759, giving 0=0.759+1.5x−0.441x². That solves to x=3.848 or x=−0.447, i.e. θ≈75.4° or θ≈−24.1°. (A negative angle here means the target is close enough that even aiming slightly downward from the cliff still reaches it.)
