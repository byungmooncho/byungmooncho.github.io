Projectile in 2D: Launch at Arbitrary Angles

Synopsis Now we tilt the cannon. A projectile launched at speed V and angle θ above the horizontal is two problems stapled together by one clock: resolve the launch velocity (Note 2a!) into Vx = V cos θ, which never changes, and Vy = V sin θ, which behaves exactly like the vertical rocket of Module 1, Note 9 — rising, stalling (vy = 0 at the apex), and mirroring back down. The vertical motion alone sets the flight time, tflight = 2Vy/g; the horizontal motion simply cruises for that long, giving the range dx,max = Vx·tflight. Same kinematic equations as Module 1 — just run twice, once per axis.
Performance Expectations By the end of this note, you will be able to…
  • PE1Resolve a launch velocity into Vx = V cos θ and Vy = V sin θ for any launch angle.
  • PE2Describe each component's behavior in flight — Vx constant the whole time; vy changing at −9.8 m/s² with vy = 0 at the apex.
  • PE3Calculate the flight time for a launch that lands at its starting height: tflight = 2Vy/g = 2V sin θ / g.
  • PE4Calculate the maximum height using the vertical motion alone (vy² = Vy² + 2(−g)d with vy = 0 at the top).
  • PE5Calculate the range — dx,max = Vx·tflight = (V cos θ)·tflight — and reason about how angle trades height against distance.
  • PE6Set up a cliff-top launch — recognize that an elevated launch keeps the same components but changes the vertical landing condition. (You'll put this to work on real targets in Note 5.)

💡You already know this

You've been optimizing launch angles since the playground:

🏀 The arc of a shot A flat shot gets there fast but barely clears the rim; a high arc hangs forever. Angle trades speed-across for time-aloft.
🚿 Hose distance contest Aim too low and the water lands short; too high and it comes straight back down. The sweet spot is in the middle — near 45°.
🏈 Kickoff vs. punt A kickoff is for distance (lower arc); a punt is for hang time (higher arc). Same field, different components.

The key equations, by axis

One table runs this whole note. Resolve first; then read each column as its own Module-1 problem sharing one clock. (Level-ground launch, landing at the starting height; g = 9.8 m/s².)

Horizontal componentVertical component
Velocity (m/s) Vx = V cos θ — constant all flight Vy = V sin θ at launch; changes by −9.8 m/s each second
Flight time (s) — (the horizontal motion has no say) tflight = 2Vy/g = 2V sin θ / g
Max. displacement (m) dx,max = Vx·tflight = (V cos θ)·tflight dy,max = Vy²/(2g) — from vy = 0 at the apex

Looking ahead: everything here launched from level ground and landed at the same height. Launch from a cliff top — or a lab bench — and the components stay the same but the vertical landing condition changes. That's exactly the setup of Note 5, where you'll run today's equations backwards to aim a real launcher at real targets (and earn exam bonus credit doing it).

The engines underneath: Module 1's equations

Nothing new was invented for 2D — each axis runs the same three kinematic equations you mastered in Module 1 (with a = −9.8 m/s² vertically, a = 0 horizontally):

📍 d = d₀ + v₀t + ½at² Position from time — the vertical version draws the arc; the horizontal version (a = 0) is just d = v₀t.
🚀 v = v₀ + at Velocity from time — sets vy = 0 at the apex and gives the flight-time formula.
⛰️ v² = v₀² + 2ad Velocity from position — no clock needed; the fastest route to the maximum height.
