Resolving A Vector

Synopsis Head-to-tail addition joins two vectors into one. Resolving a vector is that process in reverse: instead of combining two vectors into a resultant, we split one vector into two perpendicular parts — a horizontal component and a vertical component — that, added head-to-tail, reconstruct the original vector exactly. A vector that already lies flat along an axis needs no resolving at all: it's entirely one component and zero the other. Resolving is the tool that lets us add vectors algebraically instead of just diagrammatically — add the horizontal parts together, add the vertical parts together, and reassemble.
Performance Expectations By the end of this note, you will be able to…
  • PE1Recognize resolving as the reverse of head-to-tail addition — splitting one vector into two perpendicular parts instead of combining two into one.
  • PE2Resolve a vector into its horizontal (x) and vertical (y) components by drawing a right triangle: the component legs run along the axes, and the original vector is the hypotenuse.
  • PE3Recognize when a vector needs no resolving — a vector already lying along the x-axis or y-axis is entirely one component; its other component is zero.
  • PE4Resolve two or more vectors, then add their components separately — sum all the x-components together, and all the y-components together.
  • PE5State the component-addition rule — Cx = Ax + Bx and Cy = Ay + By — and explain why adding components independently gives the same resultant as head-to-tail addition.
💡You already know this

Splitting one diagonal thing into two straight parts isn't new — you've done it before:

📺 TV screen size A "55-inch" TV is measured along the diagonal, but the screen really has a width and a height. The diagonal is one number standing in for two perpendicular ones.
🚶 Cutting across a field Walk diagonally across a rectangular field instead of around the two edges — you still end up some distance east and some distance north, just covered both at once instead of one leg at a time.
🎮 Pushing a joystick diagonally Push a game controller stick diagonally and the game doesn't see "diagonal" — it resolves your push into an x-push and a y-push and moves your character by both, separately.

  3. What happens when we add two vectors' components separately — do we get the same resultant as adding the vectors head-to-tail?
  4. Why does a vector already lying along an axis need no resolving?
