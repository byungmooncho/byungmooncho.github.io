Resolving a Vector

Synopsis We can add vectors with the head-to-tail rule. Now we run that rule in reverse: any vector can be resolved — split up — into a horizontal component (along x) and a vertical component (along y) that, added head-to-tail, rebuild the original exactly. Resolving is the single most useful move in this module, because of a quiet miracle you'll discover in this note: components add like ordinary numbers. If A and B add to the resultant C, then C's horizontal component is just A's plus B's — and the same holds vertically. Vector addition becomes arithmetic, done separately along x and along y.
Performance Expectations By the end of this note, you will be able to…
  • PE1Explain what resolving a vector means — splitting it into horizontal and vertical components that together have the same effect as the original.
  • PE2Resolve a vector by drawing — use a ruler to construct its component along x and its component along y on grid paper.
  • PE3Assign the correct signs to components from the vector's direction (e.g., up-and-left → x negative, y positive).
  • PE4Resolve special cases — a vector lying along an axis has one component equal to the whole vector and the other equal to zero.
  • PE5Show that components add — if A + B = C, then Cx = Ax + Bx and Cy = Ay + By.
  • PE6Recognize the payoff — components turn vector addition into ordinary number addition, one axis at a time.

💡You already know this

Splitting one motion into "how much sideways" and "how much up" is something you do by instinct:

🥾 Hiking northeast Walk 5 km northeast and you've gone some east and some north — two separate answers hiding in one arrow.
🛒 Pushing a cart handle Push down a tilted handle: part of your push drives the cart forward, part presses it into the floor. One force, two jobs.
🪜 A leaning ladder A 3 m ladder against a wall reaches less than 3 m up — how much less depends on how far its foot sits out. Length splits into across + up.

Component signs at a glance

Before you compute anything, read the signs straight off the arrow's direction:

The vector points…x-componenty-component
Up and to the right ↗++
Up and to the left ↖−+
Down and to the right ↘+−
Down and to the left ↙−−
Exactly along an axis → or ↑one component is the whole vector; the other is zero

Three rules to remember

✂️ V → Vx + Vy Resolving splits one vector into a horizontal piece and a vertical piece that rebuild it head-to-tail.
➕ Cx = Ax + Bx Components of the resultant are the sums of the components — the same along y: Cy = Ay + By.
🔢 Vectors → numbers The payoff: with components, vector addition becomes ordinary addition, done separately along x and along y.
