Fitting Data Using Vernier Graphical Analysis

Adapted from the lab supplement by Dr. H. Trevor Johnson-Steigelman for FLCC Physics.

The goal Fit data gathered with Vernier probes — ultrasonic distance sensors, force sensors, angular rotation sensors, and others — using the free Vernier Graphical Analysis program. Every fit follows the same seven-step routine:
  1. Open the data set.
  2. Examine the data.
  3. Select the data.
  4. Fit the data.
  5. Save an image of the graph.
  6. Record the fitting parameters.
  7. Fit the rest of the data.

Get the software

Graphical Analysis is a program created by Vernier, a company that provides sensors and software to science classrooms around the world. It replaces an older program called Logger Pro; while Graphical Analysis has fewer features, it is a little easier to use — and it is free.

To get it, go to vernier.com/product/graphical-analysis/free/ and click on the appropriate link for your computer system. There are versions for Windows, macOS, the Chrome web store, Google Play, and the Apple App store.

Open the data set

After installing the software, open it and you should see something like the screen below. Each platform may show things slightly differently, so you may have to look around.

Click on the “Choose File” button and go to the folder where you have downloaded or stored your data.

Use the .csv version of the data The older .cmbl versions are not always compatible with Graphical Analysis. You will likely have to set the file-type drop-down to Comma Separated Values (*.csv) to see the data files. Some labs may have .gambl files available.
Seeing the data The data may be visible right away. If no data shows up, click on the y-axis — you should be given an option of what data sets to display.

Examine the data

Data gathered by Vernier probes is usually not “cleaned” in any way. It will include data gathered before and after the part of the experiment that is of interest.

In the data above, a rolling cart was being pulled by a dropping mass, and the graph shows the position of the cart as a function of time. There are about 0.75 s at the beginning taken before the cart was released, and all of the data after about 2.5 s was gathered after the cart was stopped.

We need to be careful to analyze only the part of the data where the cart was freely accelerating. We do not want to be too close to the beginning or end of this window, so we should probably only consider the data from about 1.25 s through 2.25 s.

Select the data

To select the data, simply put your mouse over the graph at around 1.25 s, hold down the mouse, and drag to the right. The program will try to snap the end points to the actual times collected — do not worry if you can’t select exactly 1.25 s to 2.25 s. In the example below the selected range is 1.10 s to 2.45 s. You can grab the boxed numbers on the edges of the fit area and move them left or right to your liking.

Every data set is different Each data set will have a different range of interest, affected by how long the run takes, how much time passed before the object was released, and other factors. The key is to fit only the data that is appropriate for the model you are using. Here the cart accelerates at a constant rate, so we fit only the accelerating part — leaving out where it sat at rest before and after the experiment.

Fit the data

Once you have the appropriate data selected, click on the “Graph Tools” icon in the lower-left corner of the program window — it is the one that looks like a small graph. When the menu appears, click on “Apply Curve Fit”.

The default curve fit is a linear fit. If you look closely, this does not fit the data well.

To pick the proper fit, think about the model we are using. Use the drop-down menu to see all the options.

The model: constant acceleration

x = xo + vo Δt + ½ a (Δt)2

An accelerating object should follow this model equation — a polynomial of order two. So we choose the “Quadratic” option from the drop-down menu.

After you pick the appropriate curve fit, click on the “Apply” button. You will now see a new box containing the fit equation type and the fitting parameters. You can move this box up and down to avoid covering your data set.

Save an image of the graph

We want to include this data in our lab reports. It is a good idea to adjust the size of the program window so that it is not the full size of your screen (on iPads and Android devices you might not have this ability). After adjusting the size, make sure the numbers and other info are clear, and move the fitting-parameters window again if you need to.

Once the window is appropriately sized, take a screen shot of it — use the appropriate screen-grab tool (Alt+PrtSc or Snip & Sketch for Windows, Shift+Command+4 for Mac, etc.). Then paste the screen shot into the appropriate section of your lab report.

Record the fitting parameters

You will also want to record the fitting parameters — it is very likely that you will use at least some of these numbers in your analysis. Note the form of the fitting equation and the letters listed beneath it, and match these to your model.

Fit the rest of the data

You will likely have other data to fit. Make sure you save your information in case you need to come back to it. To save the data, click on the name of the file in the upper left-hand corner of the program window — there are a few options there for opening a new file and saving the current one.

About the Export option There is also an “Export” option that can save images, but a screen-grab tool usually gives a better-sized image for lab reports.

Review

  • Open your data as the .csv version via Choose File; if nothing shows, click the y-axis to pick a data set.
  • Raw probe data is not cleaned — examine it and find the region where the model actually applies.
  • Drag across the graph to select that region; adjust the boxed endpoints as needed.
  • Fit with Graph Tools → Apply Curve Fit, and pick the fit that matches your model equation — not the default.
  • Screen-shot the sized window for your report, and record the fitting parameters, matching the fit letters to your model.
  • Save your file before moving on to the rest of your data.
