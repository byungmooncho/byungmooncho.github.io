Formatting Data Tables for Lab Reports

How to turn raw Excel data into a clear, professional table for your lab report · Video: Physics This Week (11:17)

After watching this video, you should be able to:

  • Label data columns with quantities and units (e.g., Time (s), Distance (m)).
  • Display a consistent number of decimal places that matches the precision of your measurements.
  • Align numbers so decimal points line up and trends are easy to see.
  • Apply clean borders to a finished table.
  • Transfer the table into a Word lab report so it stays intact.

TimeStep
Add units to your labels. Every column header states the quantity and its unit. Bold the headers, adjust font and size, and resize columns so labels fit.
Set the decimal display. Excel drops trailing zeros (typing 1.00 shows 1). Select the column and use Increase/Decrease Decimal so every value shows the precision you actually measured.
Align the numbers. Keep numbers right-aligned so decimal points line up, then use Alignment → Right (Indent) to add breathing room inside the cell. Avoid center alignment — decimals stop lining up.
Fix calculated columns. Formulas show as many digits as possible, like a calculator. Reduce the decimals so calculated values match your measurement precision.
Add borders. Select the table, apply All Borders, then a Thick Outside Border (and one under the header row). Follow your professor's or journal's specific requirements if given.
Copy the table into your lab report. Copy in Excel, then in Word paste as a Picture. Avoid linked paste — if the Excel file moves or changes, the table in your report can break.
Position it in the document. Select the pasted table, open Layout Options, and choose Square so your text wraps beside the table and you can discuss the data right next to it.
Why alignment matters: when decimal places are consistent and lined up, your eye can follow the trend in the data down the column. Misaligned, ragged numbers hide the pattern.
