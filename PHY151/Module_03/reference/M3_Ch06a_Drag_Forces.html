Drag Forces

Web version of the lecture slides by Dr. H. Trevor Johnson-Steigelman (Physics This Week), adapted for PHY 151.

The idea Every force so far has been indifferent to how fast the object was going. Drag is not: it grows with the square of speed, so it is negligible when you start and decisive by the time you are going fast. That single feature explains why a falling object stops speeding up, why a parachute works, and why the projectile ranges from Module 2 were all quietly labelled “no air resistance”.

Air resistance

The drag equation
FD = ½ CD ρ A v2
SymbolMeaningWhat changes it
CDdrag coefficient material, shape, surface texture — even hair
ρdensity of the air (Greek letter rho) altitude, temperature
Across-sectional area your posture — the silhouette the air actually meets
vspeedsquared, so it dominates everything else

The direction is opposite to the velocity, always. Drag never speeds anything up and never pushes sideways; it is defined against whatever direction the object is already going.

Domain of validity — this is a simple model The v2 form above holds for “low” speeds (< 200 m/s), small diameters (a few metres at most), and air causing the drag. Outside that window the physics is different, which is why the next page treats liquids with a completely different equation. Trevor puts this box on the slide itself — treat it as part of the formula, not a footnote.
A loose end from Module 2, tied off “This is why we used constant speeds in relative-motion problems.” Once drag is in play, nothing coasts at a fixed speed for free — so every clean kinematics problem you have solved so far has been quietly assuming this force away.

Terminal velocity

Drop something. At the start v = 0, so the drag force is zero and the object accelerates at g. As it speeds up the drag grows — as v2, so quickly — until it exactly cancels gravity. From then on the net force is zero and the speed stops changing.

Terminal velocity occurs when acceleration no longer occurs
ΣF⃗ = 0  →  Fd − Fg = 0  →  Fd = Fg
½ CρAv2 = mg  →  v2 = 2mgCρA  →  v = √2mgCρA

This is an equilibrium condition, not a new law — the same ΣF⃗ = 0 as the hanging-sign problems, with a speed-dependent force in it. A falling skydiver at terminal speed is in dynamic equilibrium, moving at 50 m/s with zero net force on them.

Read the formula, then read the sky-diver Terminal speed goes as √m/A. Spread out flat and A is large, so v is small — the stable belly -down posture. Dive head-first and A collapses, so the speed climbs; that is a “no-lift dive”. Open a parachute and A jumps by a factor of tens, so the terminal speed drops by a factor of several — which is the entire engineering of the thing.

Very small objects — Stokes’ law

A different regime, a different equation
Fs = 6πrηv
SymbolMeaning
rradius of the object
ηviscosity of the fluid
vvelocity — note, to the first power

Very small objects follow Stokes’ law instead. The physical difference is that the air is being pushed aside smoothly rather than slammed into, so the resistance tracks v rather than v2. This is why fog droplets hang in the air and raindrops do not.

Not the same Stokes Stokes’ law here is not Stokes’ theorem from the calculus sequence. Same man, unrelated results.

Review

  • The drag force on an object depends on the drag coefficient, the air density, the cross-sectional area, and the square of the speed.
  • It points opposite the velocity.
  • Terminal velocity is reached when drag balances gravity — a dynamic equilibrium.
  • Very small objects obey Stokes’ law, which is linear in speed.
