Equilibrium

Web version of the lecture slides by Dr. H. Trevor Johnson-Steigelman (Physics This Week), adapted for PHY 151.

The idea Equilibrium is not “not moving”. It is “not accelerating” — which is a much larger class of situations, and includes a hockey puck gliding across frictionless ice at 30 m/s. Once you accept that, equilibrium problems become the easiest kind in the whole course: set ΣF⃗ = 0, split it into components, and solve. The hanging-sign problems at the end are the standard workout.
Performance Expectations By the end of this lesson, you will be able to…
  • PE1State the conditions for equilibrium.
  • PE2Distinguish static from dynamic equilibrium.
  • PE3Determine the force or forces required to keep an object in equilibrium.

The two conditions

An object is in equilibrium when both of these hold
ΣF⃗ = 0    and    Στ⃗ = 0

The net force on the object is zero, and the net torque on it is zero. Module 3 works entirely with the first condition, because everything here is a point mass or is treated as one. The torque condition is what the statics module is built on — it is stated now so that “equilibrium” does not have to be redefined later.

Static equilibrium— in equilibrium and at rest
Dynamic equilibrium— in equilibrium while moving — at constant velocity
This is Newton's first law wearing a different hat “Net force zero” and “velocity constant” are the same statement. So the distinction between static and dynamic equilibrium is about the observer, not the physics: a box at rest in the room is a box in dynamic equilibrium to someone walking past it at a steady pace. Which is Note 1’s point exactly — there is no experiment that tells the two apart.

Are these objects in equilibrium?

SituationVelocityAccelerationNet forceEquilibrium?
Box at rest on a level floorv = 0 a = 0ΣF⃗ = 0 Yes — static
Box pushed at a constant speedv ≠ 0 a = 0ΣF⃗ = 0 Yes — dynamic
Hockey puck on frictionless ice, no air resistancev ≠ 0 a = 0ΣF⃗ = 0 Yes — dynamic
Ball at the top of a vertical tossv = 0 a = −g ≠ 0 ΣF⃗ = Fg ≠ 0 No
Object in uniform circular motionv ≠ 0 a = ac ≠ 0 ΣF⃗ = Fc ≠ 0 No
Object sliding down a frictionless inclinev ≠ 0 a = g sin θ ≠ 0 ΣF⃗ = mg sin θ ≠ 0 No
The two rows to stare at The ball at the top of a toss has zero velocity and is not in equilibrium. The hockey puck is moving fast and is. Between them they dispose of the intuition that equilibrium has anything to do with being still. Acceleration is the only thing the definition looks at.
A slip in the source deck Trevor’s slide writes ΣF⃗ = Fg for the uniform-circular-motion case as well as for the tossed ball — the label was carried over from the panel beside it. His own figure has it right: the net force there is the centripetal force Fc, pointing at the centre of the circle. Corrected in the table above.

Hanging objects

The standard problem: a sign hangs from two ropes at different angles, and you want the tension in each. Three habits keep it clean:

  • Make sure you are looking at the proper angles. The angle in the equation is the one the rope makes with your chosen axis, which may not be the one drawn on the diagram.
  • Work from the object, not the support. Draw the free body diagram of the sign. The ceiling has its own forces on it and they are not your problem.
  • Don’t forget about gravity. It is the force students leave off, because it is the one with no rope attached to it.
Two directions, two equations, two unknowns
Horizontal (x)Vertical (y)
0 = ΣFx = −Flx + Frx 0 = ΣFy = Fly + Fry − Fg
0 = −Fl cos θl + Fr cos θr 0 = Fl sin θl + Fr sin θr − mg

Note the asymmetry: the horizontal components must cancel (one is negative), and the vertical components must add up to the weight. That is the shape of every hanging problem you will meet.

Worked example — what is the tension in each of the ropes?

A 10.0 kg sign hangs from two ropes, the left at θl = 30.0° and the right at θr = 45.0° above the horizontal.

Use the horizontal equation to eliminate one unknown
Fl = Fr cos θrcos θl   →  substitute into the vertical equation:
mg = Fr (cos 45°cos 30° sin 30° + sin 45°) = Fr (1.1154)
Fr = mg1.1154 = (10.0 kg)(9.80 m/s2)1.1154 = 87.86 N → Fr = 87.9 N
Fl = 87.86 N cos 45°cos 30° = 71.74 N → Fl = 71.7 N

Sanity check the answer before you write it down. The two tensions sum to 159.6 N against a 98 N weight — more than the thing they are holding up, because most of each rope’s pull is spent cancelling the other rope horizontally rather than lifting. The shallower rope (30°) carries the smaller tension here because the steeper one is doing more of the lifting.

Push the result Flatten both angles toward horizontal and 1.1154 shrinks toward zero, so the tensions grow without bound. That is why a clothesline can never be pulled perfectly straight, and why a tow rope stretched taut between two cars is far more dangerous than a slack one.
