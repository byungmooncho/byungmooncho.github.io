Tension Forces in a Hanging Object

Synopsis An object held in mid-air by two strings is the simplest two-dimensional equilibrium there is, and it hides a genuinely surprising result. The strings do not share the load in any fixed way — how hard they pull depends entirely on the angle they make, and as they flatten toward horizontal the tension does not level off. It runs away to infinity. This note is where you resolve vectors into components and sum them separately, which is how every mechanics problem from here on is going to work.
Before you read on — predict A heavy sign hangs from two wires fixed to a wall. It sags in the middle and looks untidy, so you tighten both wires to pull it up closer to horizontal.
Does tightening the wires make them safer, or more likely to snap? Commit to one, with a sentence of reasoning, before you turn the page.
Performance expectations
  1. Draw the free-body diagram of an object hung by two strings, and state which way a tension force acts.
  2. Resolve each tension into horizontal and vertical components and build the component table, with the correct sign on each entry.
  3. Write ΣFx = 0 and ΣFy = 0 as two independent equations, and use the first to show T1 = T2 when the angles are equal.
  4. Derive T = mg / (2 sin θ) and use it.
  5. Predict how the tension changes as the strings are lengthened or shortened, and explain why a perfectly horizontal string is impossible.
  6. Explain why the vertical components are the same at every angle while the horizontal components are not.
One convention, fixed for this whole note

θ is measured from the ceiling — that is, from the horizontal. Every equation on this page assumes it. Get this wrong and every sine becomes a cosine.

Check it on the figure below before you go on: when the strings are nearly horizontal, θ is small. When they hang straight down, θ = 90°.

The setup

  1. Draw this free-body diagram yourself. Two tension forces pointing away from the object along the strings, and the weight. Mark θ at each string.
  2. Resolve each tension into its two perpendicular components, head to tail. Which side of the right-angled triangle is adjacent to θ, and which is opposite?
  3. Write T1x, T1y, T2x and T2y in terms of T and θ. Watch the signs — a vector pointing left takes a negative sign, and so does one pointing down.

Two directions, two equations

The object is in equilibrium horizontally and vertically, so the forces add to zero in each direction separately. That is two independent equations, and it is the habit this note is really teaching. Fill the table from your own diagram.

The key relationships

  • 2Tsin⁡θ=mg the vertical components carry the whole weight, between them
  • T=mg2sin⁡θ equal angles only. θ from the horizontal
  • Ty=mg2 each string's vertical pull — the same at every angle
  • Tx=mg2tan⁡θ the horizontal pull — unbounded as θ → 0
Where these hold

All four assume equal angles, which follows from equal string lengths. If the strings are different lengths the angles differ, T1 ≠ T2, and you go back to the component table — which still works. Only the shortcut breaks, not the method.

  1. An object of mass 2 kg hangs with the strings at 30° from the ceiling. Find the tension in each string.
  2. You replace the strings with longer ones, same anchor points. What happens to θ, and what happens to T? Explain using the equation.
  3. Now use strings so short that they are almost horizontal. What happens to T, and what would that mean in practice?
  4. If you want the tension as small as possible, should the strings be long or short? What is the smallest tension you could ever achieve?
  5. You can never actually reach a 0° angle — perfectly horizontal strings. Why not? What happens to the string before you get there?

Why the two components behave so differently

This is the part worth slowing down for. Each string's vertical pull is T sin θ, and substituting T = mg/(2 sin θ) gives exactly mg/2 — the sines cancel. The two strings always split the weight evenly between them, at any angle. They have no choice: the weight is the only thing they have to hold up.

The horizontal components are a different story. They are not holding anything up — they are pulling against each other, and nothing caps how hard. As the strings flatten, each must pull harder and harder sideways just to keep its vertical share at mg/2. That is where the tension runs away, and it is why the answer to the sign question is more likely to snap.

  1. As θ increases, what happens to the vertical component of the tension? And to the horizontal component? Justify both from the equations.

Check it on the bench

  1. Set up a 2 kg object hung by two strings at 30° from the horizontal. Calculate the tension first. Then measure it, and compare. If your measured value sits below the calculation, check your angle before you doubt the physics — a few degrees matters a great deal down at this end of the curve.
Where this goes. The component table you built here is the general method — it does not care whether the angles are equal, whether there are two strings or three, or whether the surface is tilted. Note 7 used the same move with the axes rotated to a slope. Any problem with forces in two directions gets solved this way: resolve, sum each direction separately, set each sum to zero if nothing is accelerating.
