Two terms to know before we start: an Excel file is referred to as a Workbook. A page (or tab) within it is referred to as a Worksheet. The worksheet tabs are like the tabs in your browser, but they appear at the bottom of the screen. You can adjust the display size using the zoom slider in the lower right-hand corner of the Excel window.

Why Use Excel?

Excel is one of the most powerful programs in the world. It allows you to arrange information in multiple ways, and:

  • It can do many calculations very quickly, including repetitive calculations.
  • It can be updated almost instantaneously — change one number and everything that depends on it recalculates.
  • Information can be linked or shared to Word and PowerPoint.
  • It can rearrange data in multiple ways.
  • It can make reports quickly using tables and pivot tables. (Next class.)
  • It can make charts and graphs.

For example, in the table below, the Revenue column is calculated from the price per item. If you change the price from $10.00 to $15.00 in Excel, every number in the Revenue column updates instantly:

Other things Excel can do (beyond the scope of these classes): it can be accessed by multiple users and updated instantly, and it can be “programmed” using Visual Basic.

Terminology: The Parts of the Excel Window

  • Menu Bar — the row of words across the top: File, Home, Insert, Page Layout, Formulas, Data, Review, View, Help.
  • Ribbon — the wide strip of buttons under the menu bar. Its contents change depending on which menu you pick.
  • Commands and Command Groups — the individual buttons (commands) in the ribbon are organized into labeled groups, such as Clipboard, Font, and Alignment.
  • Formula Bar — the long box just above the grid (marked fx). It shows the actual contents of the selected cell — the formula, not just the displayed value.
  • Columns — run vertically and are labeled with letters (A, B, C, …).
  • Rows — run horizontally and are labeled with numbers (1, 2, 3, …).
  • Cells — the individual boxes in the grid. Each cell is named by its column letter and row number: cell D2 is in column D, row 2.
  • Active Cell — the cell you have selected, shown with a green border. Its name appears in the Name Box at the left end of the formula bar.

Setting Up Your Document to Be Printer Friendly

  1. Go to the View menu above.
  2. Pick the Page Layout option from the “Workbook Views” command group. Now you can see where the printed page edges fall.
  3. Click on the Page Layout tab in the menu bar. (Yes, this is confusing — the tab and the view have the same name.)
  4. Adjust the orientation, portrait or landscape, using the Orientation command icon.
  5. Set the page margins using the Margins command icon. Choose the “Custom Margins” option. I like to leave an inch on the side that might be bound, and 0.5 inches on the rest.
  6. Watch the right edge: the last column on a page might “jump” to the next page if it is too big.

Tips

  • Don’t cross the page edges if you can help it. (This isn’t always possible.)
  • Put things you don’t need to see in print on a separate page (same worksheet, though).
  • Play with font sizes and column widths to make it look nice.
  • Look at the print preview (next section) before printing.
  • You can click on the edges of the pages to hide the margins while working.

Printing Your Workbook

  1. Click on File to open the backstage view.
  2. Click on Print from the menu on the left.
  3. Adjust the pages to print under Settings.
  4. You can adjust other options here too.
  5. Make sure you have the proper printer.
  6. Hit Print.

Cell References

It is generally good practice to do things using cell references rather than retyping numbers.

  • Each cell has a label based on its column and row, like A3.
  • The active cell has a green border.
  • When you double-click a cell, it shows its formula; otherwise it shows its value. You can also see the formula in the formula bar above.

Types of Cell References

ReferenceMeaning
A5A relative reference — it shifts when the formula is moved or copied.
$A$5A fixed (absolute) reference — the dollar signs ($) lock it in place.
$A6Fixes the column only.
A$7Fixes the row only.
(A5:A15)An array — a range of cells, from A5 through A15.

Be careful about how you reference cells in formulas, especially when you move or copy a cell. Dragging or copying a formula into other cells moves the un-fixed (relative) references along with it. If a copied formula suddenly gives nonsense — like a revenue of $0 — double-click it and check where its references ended up pointing.

Rows and Columns

  • You can adjust the sizes of rows and columns: place your mouse on the line between the column letters or row numbers. A new icon appears — drag to make it fit. Changing the width changes the whole column, so think a bit about design.
  • Auto-sizing is done by double-clicking on the line between column letters or row numbers.
  • Re-sizing cells is finicky. Realize you might have to play with it to get what you want.
  • Cell contents will spill into the next cell if it is empty; otherwise the display gets cut off. You might need to adjust the size of the last cell to keep it on the page.
  • You can highlight cells using the paint bucket icon.
  • You can insert new rows and/or columns using command icons in the Home tab. This option isn’t available in the “Insert” tab. (Yes, that’s confusing.)

The Cursor in Excel

The behavior of the cursor in Excel takes some getting used to. Its appearance changes depending on where you are on the page.

  • While in the ribbon, it appears “normal,” as an arrow. If you hover over a command icon, it will give you info about the command.
  • While in the worksheet part of the window, it can take several forms, depending on where you are on or in a cell:
    • A thick white cross over the middle of a cell — click to select.
    • A four-headed arrow on the edge of a selected cell — drag to move the cell.
    • A thin black cross on the small green square at the bottom-right corner of a cell — the fill handle, used to copy formulas (see Fast Formulas below).
  • If you click into a cell, the cursor becomes a single vertical line, indicating where the next character goes.

Creating Formulas

Formulas always start with an equals sign ( = ).

You can build basic formulas using math symbols:

OperationExample formulaWith H = 12, I = 4, the result is
Addition=H9+I916
Subtraction=H10-I108
Multiplication=H11*I1148
Division=H11/I113

You can also group terms using parentheses — and the grouping matters. With the values 12, 4, and 6:

Add, then divide=(H15+I15)/J15(12 + 4) / 6 = 2.6666667
Divide by a sum=H15/(I15+J15)12 / (4 + 6) = 1.2

To use a cell in a formula…

  1. Type an equals sign in the cell you want the formula to be in.
  2. Type the cell reference OR click on the cell containing the number.
  3. Put in the appropriate operator ( + , − , * , / ).
  4. Type the next cell reference OR click on the cell containing the number.

Note: Sometimes clicking on cell references can get tricky. You can use fixed references (like =$H$19+$I$19) to keep using the same cell(s) over and over again.

Other formulas are available using the Formulas tab.

Fast Formulas: Applying the Same Formula Multiple Times

To copy a formula, you have several options. Be aware that relative references move with your cell.

The easiest way for a single formula is to just copy and paste the cell with the formula. If you are applying it to a whole column of data:

  1. Type the formula into the first data row of the column.
  2. Press Enter.
  3. Move the cursor over the green square at the bottom right of the cell (the fill handle).
  4. Drag down as far as you want it. Or, if you double-click the fill handle, it fills the formula down for all adjacent rows automatically.

Example: in a table of labor charges, the Cost column would be one formula — price/hr × time — typed once in the first row and filled down:

Tips

  • Only include numbers in a cell. Place units in a separate cell or as a heading. If a cell contains numbers and letters (like “12 in”), the whole thing is treated as text and can’t be used in calculations.
  • Numbers align to the right by default; text aligns to the left. You can play with alignment to make things look better.
  • You can adjust the font and character size in the “Font” command group.
  • If nothing is in the next cell, text content will continue across; numbers will usually round to fit.
  • For a cell that starts with an equals sign but that isn’t a formula, start with an apostrophe: typing '=formula displays =formula.
  • For a cell that contains numbers meant to be text, also use the leading apostrophe.

Decimals

Excel will display as many decimal places as will fit. You can adjust them:

  1. Go to the Home tab.
  2. Look for the Number command group.
  3. Select the cells you want to fix, then use the increase/decrease decimal command icons to adjust the display.

For example, setting the second column below to 2 decimal places:

Note: this changes only the display — Excel still calculates with the full value.

Aligning Cells

  • Use the alignment tools in the Home tab. The lines icons adjust the placement within the cells (top, middle, bottom, left, center, right). You can also adjust the direction of text.
  • You can wrap text by clicking on the Wrap Text command icon in the Home tab. Wrap Text allows multiple lines within a cell. (This affects the whole row’s size.)
  • Control-Z is the Undo button, just like in Microsoft Word.
  • You can Merge & Center text across a series of cells by selecting them and choosing the “Merge & Center” icon. You can adjust the alignment after doing this — it doesn’t have to stay centered.
  • Merge and center can cause some stress when moving cells, and if you merge cells that each contain information, you will get a warning — only the upper-left value is kept.

Common Math Formulas

Built-in functions follow the pattern =FUNCTIONNAME(Field1, Field2, [OptionalField], …)

Using the sample data 24, 23, 33, 35, 24 (five cells):

To find a(n)…FormulaResult
Sum=SUM(cells or array)139
Average=AVERAGE(cells or array)27.8
Standard deviation=STDEV.S(cells or array)5.7
Maximum value=MAX(cells or array)35
Minimum value=MIN(cells or array)23
Count of cells=COUNT(cells or array)5

Note: Multiple forms of some formulas exist — use search or Help. Most of these functions are also available to the far right of the Home tab (AutoSum).

Other Formulas

You can find even more formulas in the Formulas tab above. Chances are that there is a built-in function for just about anything you might need in Excel.

Conversions

To convert units, you can make your own formula:

ConversionFormulaStartResult
Inches to feet=D6/1224 in2 ft
Miles to km=D7*1.62 mi3.2 km
Minutes to hours=D8/60120 min2 hr

Or use Excel’s built-in CONVERT function: =CONVERT(number, "from_unit", "to_unit")

ConversionFormulaStartResult
Pounds to stone=CONVERT(D13,"lbm","stone")190 lb13.57 st
Miles to kilometers=CONVERT(D14,"mi","km")1 mi1.609 km
Celsius to Fahrenheit=CONVERT(D15,"C","F")37 °C98.6 °F
  • A list of unit symbols will appear if you place your cursor in the formula.
  • Your answer may have lots of decimal places — you can adjust their display as needed (see Decimals).
  • Don’t put the number and the unit in the same cell. Use the next cell for the unit.

Trig Functions

Excel only calculates sine, cosine, tangent, etc. from angles in radians, so these conversions are important:

To convertFormulaExample
Degrees to radians=RADIANS(angle)30° → 0.52 rad
Radians to degrees=DEGREES(angle)3.14 rad → 179.91°

Trig functions, for angles given in degrees:

FunctionFormulaAngle (°)Result
Sine=SIN(RADIANS(angle))300.50000
Cosine=COS(RADIANS(angle))300.86603
Tangent=TAN(RADIANS(angle))300.57735

If your angles are already in radians, the conversion isn’t necessary — use =SIN(angle), =COS(angle), etc. directly.

To use π “exactly,” use the function =PI(), which gives 3.1415927…

Note: Trig functions that evaluate to near zero might show up as very small numbers (like 2.65E-06), not exactly zero. That is normal round-off, not a mistake.
