Air Rocket Vertical Launch

The Big Question: How do we get to another planet?

Synopsis Gravity perpetually pulls us toward the center of the Earth; to reach another planet, a rocket's propulsion must completely overcome that pull. Newton showed a rocket can escape Earth's pull entirely if launched fast enough — the key is launch speed, called the escape velocity (≈11,000 m/s). In this lab, we launch an air rocket to model a vertical launch: we measure its flight time, use it to find the rocket's initial velocity, and then find the maximum height it reached.
Performance Expectations
  • PE1Launch air rockets at four thrust levels (low, medium, high, super) and measure flight time.
  • PE2Determine initial launch velocity from flight time using vf = vi + at.
  • PE3Determine the maximum height reached by the rocket.

9) The flight time is 6 s. Calculate the initial velocity and the maximum height reached. Show all work.

1) The negative sign means the upward motion must fight against the gravitational force, because this force pulls everything downward, opposite to the upward motion.

2) 3 s — by symmetry (mirror image), the trip up takes exactly half the total flight time.

3) Because it is the instant the rocket switches from moving upward to moving downward — velocity must pass through zero to reverse direction.

4) At the apex, vf = 0. Using vf=vi+at with t = tflight/2 (time to the apex): 0 = vi + g(tflight/2), so vi = −g(tflight/2).

5) The length represents speed. The arrowhead indicates direction. The arrow as a whole represents velocity.

6) Velocity has a direction; speed does not (speed is just the magnitude/length).

7) (i) By the up/down mirror symmetry of the trajectory, the rocket returns to the same height with the same speed it left with. (ii) It's moving downward instead of upward, so with upward defined positive, that velocity is negative.

8) vf,ground = −30 m/s.

9) vi = −g(t/2) = −(−9.8)(3) = 29.4 m/s. Max height: using vf²=vi²+2ad with vf=0 at apex: d = −vi²/(2g) = −(29.4)²/(2×−9.8) = 44.1 m.

In calculus notation

a = dv/dt = g (constant). Integrating gives velocity as a function of time; since d = ∫v dt, integrating that same function gives height — the same integration used to build the calculator and the height equation below:

v(t) = vⁱ + ∫g dt = vⁱ + gt      d = ∫v(t) dt
